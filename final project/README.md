## Overview
This project analysed, designed and implemented a web-based preliminary patient-intake workflow for a medical centre. The website introduces the centre and its services and provides an online intake form for initial patient information, medical history and supporting documents.

## Technologies documented in the thesis
- WordPress
- Astra theme
- Contact Form 7
- HTML and CSS for interface presentation
- PHP for information processing

## Workflow
1. A visitor accesses the online intake form.
2. The visitor completes required fields and may upload supporting documents.
3. The form validates required information and provides error or success feedback.
4. Submitted information is sent by email to the centre for preliminary review.
5. Other clinical forms are completed internally at the centre.

## Scope and limitations
The implemented version supports online preliminary intake and screening. It does **not** implement automated online appointment booking or a complete digital treatment workflow. The thesis states that the implemented version does not store patient submissions in a database, relies on email for receiving submissions, and has no dedicated administrative dashboard.
